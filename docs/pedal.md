# Fahrpedalsensor

Hersteller: BMW, Teilenummer: **6770935**

Das Pedalmodul verfügt über zwei unabhängig voneinander arbeitende Sensoren zur Redundanz- und Plausibilitätskontrolle. Sensor 2 gibt genau die Hälfte der Spannung von Sensor 1 aus. Der Sensor ist direkt mit der MCU verbunden.
